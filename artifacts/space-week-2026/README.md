# أسبوع الفضاء العالمي 2026

## طريقة إضافة فيديو لأي كوكب أو قسم

1. انسخ ملف الفيديو بصيغة MP4 إلى المجلد `public/videos/`. اختر اسمًا واضحًا يحدد الكوكب والقسم واللغة، مثل `earth-science-ar.mp4`.
2. افتح `src/videos.js` وابحث عن الكوكب المطلوب: `sun`, `mercury`, `venus`, `earth`, `mars`, `jupiter`, `saturn`, `uranus` أو `neptune`.
3. اختر القسم داخل الكوكب: `science` للتوعية العلمية أو `math` للرياضيات.
4. الصق مسار ملف MP4 في خانة اللغة المناسبة، مع إبقاء الشرطة المائلة الأولى، مثل:
   ```js
   earth: {
     science: { ar: "/videos/earth-science-ar.mp4", en: "/videos/earth-science-en.mp4" },
     math: { ar: "", en: "" }
   }
   ```
5. يمكنك استخدام رابط YouTube بدلًا من ملف MP4؛ الصق الرابط كاملًا في الخانة المناسبة وسيُحوّله الموقع تلقائيًا إلى مشغّل فيديو.
6. أضف رابطًا أو ملفًا مستقلًا لكل لغة وقسم. اترك الخانة `""` إذا لم يتوفر فيديو؛ ستظهر مساحة فيديو نظيفة باللغة الحالية للموقع.

لا تحتاج إلى تعديل ملفات الواجهة أو أي ملف آخر لإضافة فيديو. يقرأ الموقع جميع مصادر الفيديو من `src/videos.js` فقط.
