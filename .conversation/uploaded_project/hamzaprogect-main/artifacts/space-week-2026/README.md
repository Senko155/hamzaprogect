# أسبوع الفضاء العالمي 2026

## استبدال فيديو الرياضيات

عنوان ومسار فيديو قسم الرياضيات مضبوطَان في `src/mathConfig.js`:

- عدّل `videoTitle` لكتابة عنوان المقطع.
- ضع ملف MP4 في `public/videos/`، ثم اجعل `videoUrl` مسارًا مثل `/videos/lesson.mp4`.
- أو ضع رابط فيديو YouTube صالحًا في `videoUrl`. يُستخدم نطاق `youtube-nocookie.com` للتضمين.

عند ترك `videoUrl` فارغًا، تظهر مساحة الفيديو الافتراضية «مكان الفيديو».
